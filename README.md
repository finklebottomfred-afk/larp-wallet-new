# LARP Wallet

A fictional, local-only wallet interface. No real funds move and no banking or PayID networks are contacted.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to provide your site URL.

Data is saved in the browser's local storage on the device. It does not sync between devices. Avoid entering real personal or banking information.
